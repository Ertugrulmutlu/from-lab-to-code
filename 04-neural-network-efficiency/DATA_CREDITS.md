# Dataset and sample attribution

**MNIST** handwritten digit database: Yann LeCun and Corinna Cortes (1998), derived from NIST datasets. This project uses the official train/test splits and includes **20 small test-image samples** in `static/samples/` solely for the interactive demo.

These MNIST image samples are **not original artwork by this project**; they are attributed to the MNIST creators, and the sample data is made available under the **Creative Commons Attribution-ShareAlike 3.0** terms as documented by the [Keras dataset listing](https://keras.io/api/datasets/mnist/). The original image examples are not relicensed as part of this project's MIT-licensed code.

- Original MNIST homepage: http://yann.lecun.com/exdb/mnist/
- License: https://creativecommons.org/licenses/by-sa/3.0/
- Dataset reference: LeCun, Cortes and Burges, *The MNIST database of handwritten digits*.

No RWTH lab handouts, course notebook files, class code, university artwork, or the complete university-provided dataset are included here. Models were trained using independently authored code against the standard public MNIST dataset.
