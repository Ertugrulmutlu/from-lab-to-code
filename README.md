# From Lab to Code

**Small engineering projects. Real implementations. Clear results.**

A growing collection of self-contained Python projects that turn engineering concepts into practical, testable code. Each project focuses on a specific engineering topic, with a working implementation, interactive examples, and an explanation of the underlying ideas. Small projects, built to learn and share — no long-term product roadmap required.

**[Explore the project website](https://ertugrulmutlu.github.io/from-lab-to-code/)** · **[Read the DEV.to series](https://dev.to/ertugrulmutlu/series/45513)**

## Approach

- **Build, visualize, explain.** Each project includes runnable code, interactive demonstrations, and observable results.
- **Independent work.** The implementations and bundled demonstration assets are independently created for this series.
- **Copyright-conscious.** No university PDFs, assignment text, notebook copies, university-owned data, course logos, or other restricted course assets are redistributed.
- **Small by design.** Every project stands on its own; completed entries do not require an ongoing product roadmap.
