## Project Collection

### 01 — Image Processing

*From Theory to Pixels*

An interactive exploration of classical computer vision, demonstrating how mathematical operations transform and extract information from digital images.

**Topics:** Image filtering · Thresholding · Connected components · Fourier analysis · K-means

**Technologies:** Python, OpenCV, NumPy, Streamlit

[Source Code](01-image-processing/) · [Technical Article](https://dev.to/ertugrulmutlu/from-lab-to-code-1-exploring-classical-computer-vision-with-python-and-opencv-3mcf)

---

### 02 — Spatial Audio Playground

*From Theory to Binaural Sound*

An interactive audio environment for investigating how humans perceive sound direction and how spatial hearing can be reproduced computationally.

**Topics:** Cross-correlation · ITD/ILD · HRIR/HRTF · Binaural convolution

**Technologies:** Python, NumPy, SciPy

[Source Code](02-spatial-audio/) · [Technical Article](https://dev.to/ertugrulmutlu/from-lab-to-code-2-exploring-spatial-audio-with-python-and-scipy-3kcj)

---

### 03 — Robot Cell Playground

*From Kinematics to Automated Sorting*

An interactive 3D robotic sorting environment connecting mathematical robot models with industrial automation and control logic.

**Topics:** Forward and inverse kinematics · Finite state machines · Digital I/O · Sensors · Fault injection

**Technologies:** Python, Flask, Three.js

[Source Code](03-robot-cell/) · [Technical Article](https://dev.to/ertugrulmutlu/from-lab-to-code-3-building-an-interactive-robot-cell-with-python-and-threejs-2953)

---

### 04 — Neural Network Efficiency Lab

*Accuracy vs. Compute*

An experimental playground for comparing neural network architectures and investigating the relationship between classification accuracy, model complexity, and computational cost.

**Topics:** CNN architectures · MNIST · Feature maps · MAC estimation · Computational efficiency

**Technologies:** Python, PyTorch

[Source Code](04-neural-network-efficiency/) · [Technical Article](https://dev.to/ertugrulmutlu/from-lab-to-code-4-exploring-neural-network-efficiency-with-python-and-pytorch-1732)

---

### 05 — Real-Time Robot Control Lab

*Timing vs. Safety*

An interactive robot control simulator demonstrating how communication latency and execution strategies influence the behavior and safety of robotic systems.

**Topics:** Network latency · Blocking and non-blocking control · Braking physics · Deterministic simulation

**Technologies:** Python, FastAPI, JavaScript

[Source Code](05-realtime-robot-control/) · [Technical Article](https://dev.to/ertugrulmutlu/from-lab-to-code-5-exploring-real-time-robot-control-with-python-1j3c)

---

### 06 — SystemC Architecture Playground

*From Logic Gates to CPU Simulation*

A browser-based hardware modeling environment combining editable C++ source files, real SystemC compilation, automatic architecture extraction, and interactive simulation analysis.

**Topics:** Digital logic · Delta cycles · Ripple carry adders · CPU and memory modeling · TLM 2.0 · VCD waveforms · Automatic architecture extraction

**Technologies:** C++, SystemC, Python, Docker, JavaScript, Monaco Editor

[Source Code](06-systemc-architecture-playground/) · [Technical Article](https://dev.to/ertugrulmutlu/from-lab-to-code-6-exploring-hardware-simulation-with-c-and-systemc-5b1h)

## Project Philosophy

### Build

Translate theoretical engineering concepts into working software with reproducible implementations.

### Visualize

Make abstract algorithms, system behavior, and mathematical relationships observable through interactive experiments.

### Explain

Document the underlying theory, implementation decisions, experimental results, and technical limitations.

## Getting Started

Each project is self-contained and provides its own setup instructions, dependencies, source files, and automated tests.

Clone the repository:

```bash
git clone https://github.com/Ertugrulmutlu/from-lab-to-code.git
cd from-lab-to-code
```

Select a project and follow the instructions in its README.

## About the Series

- **Independent implementations:** Projects are developed independently for educational and experimental purposes.
- **Reproducible results:** Implementations include automated tests and practical demonstrations.
- **Copyright-conscious:** University PDFs, assignment text, restricted course materials, and university-owned assets are not redistributed.
- **Small by design:** Every project stands on its own, without requiring a long-term product roadmap.
