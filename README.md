# From Lab to Code

**Small engineering projects. Real implementations. Clear results.**

A growing collection of self-contained Python projects that turn engineering ideas into practical, testable code. Each entry is deliberately small: one concept, one working implementation, and a short explanation. No long-term product roadmap required.

## Projects

| # | Project | Topics |

| 01 | [Image Processing — From Theory to Pixels](01-image-processing/) | Denoising, thresholding, connected components, Fourier filtering, K-means |

## Approach

- **Build, visualize, explain.** Each project includes runnable code and sample results.
- **Independent work.** All code and bundled demonstration images are original.
- **Copyright-conscious.** No university PDFs, assignment text, notebook copies, university-owned data, course logos, or other course assets are included.
- **Small by design.** A new topic becomes a new entry; completed projects do not need ongoing feature development.
