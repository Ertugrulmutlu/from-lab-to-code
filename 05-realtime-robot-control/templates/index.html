01 / PHYSICS

Finite braking

The robot accelerates and decelerates at fixed rates. Required braking distance grows with speed squared.

d = v² / (2a)
02 / TRANSPORT

Delayed information

Telemetry requests and brake commands cross a virtual network with configurable delay and jitter.

RTT + jitter
03 / SCHEDULING

Blocking vs. periodic

One controller waits 500 ms between speed samples. The other polls periodically without waiting.

Δt = 10 ms
MODEL LIMITATIONS

Deterministic educational simulation, not a certified real-time controller or physical collision-prevention system. The browser demo uses a virtual network; the optional Python TCP demo uses real local sockets. Simulated latency, geometry and physics are explicitly simplified. A single seed is not a statistical performance guarantee.
